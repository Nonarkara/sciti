# SOURCES — sciti v2 dataset

All data retrieved 2026-10-19 (ICT). Free, public sources only; no paid account, card or API key was used. Every row in `indicators.csv` repeats its own `source_url`, `publisher`, `dataset`, `licence`, `period` and `retrieved`. This page groups them and says how to fetch each one again.

**Licence key.** *Open Data Common* is the Thai Government open-data licence used on data.go.th / gdcatalog: free reuse with attribution. Where a publisher states no licence, we give attribution and treat the data as public government statistics. **Wikidata is CC0.** The frontend must credit the publisher of every number it shows (EN/TH/ZH).
